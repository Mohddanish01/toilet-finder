# Toilet Finder 🚽

A public toilet finder and cleanliness rating platform.

## Features

- Add Public Toilets
- Find Nearby Toilets
- Review & Rating System
- Geo-location Search
- Crowd-sourced Data

## Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## APIs Completed

- POST /api/toilets
- GET /api/toilets/nearby
- POST /api/reviews

## Future Features

- Authentication
- PWA Support
- Heatmap for Toilet Demand
- Complaint System
